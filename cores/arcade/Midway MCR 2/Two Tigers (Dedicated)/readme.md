The soundtrack in VHD format needs to be placed in the same folder as the core and will be automatically detected at boot.
The compressed archive is available here : https://mega.nz/file/TrxCCb5A#xM5faW5a6zCaPHnC_9dJ4MGjCHsQqpHPFXriSHL8gZQ
Use the Two Tigers MAME merged ROM to generate the *.ARC and *.ROM file from the MRA.
The core in this folder mimics the behaviour of the original Dedicated Arcade cabinet with 8 tracks audio tape player.
The tape player starts rolling as soon as the P1 or P2 start button is pressed and then rolls in a loop endlessly until the core is reset.
If you want the core to behave like it does in MAME with the dedicated ROM (Tape started when P1/P2 start button is pressed and paused every time a game is finished until the next one is started), then download the core in the alternative folder.
